01 · Objetivo

Qué construimos

Una red social para deportistas, con estética mezcla de Facebook, Instagram y X, dividida en un front Angular y un back NestJS propio sobre MongoDB.

Usuarios

Registro con foto de perfil, login por correo o nombre de usuario, rol usuario / administrador.

Publicaciones

Título, mensaje e imagen opcional. Feed paginado, orden por fecha o por me gusta, baja lógica.

Interacción

Me gusta (uno por usuario), comentarios paginados y editables por su autor.

Sesión segura

JWT de 15 minutos, validación al iniciar, aviso para extender y redirección ante 401.

API correcta

Status HTTP precisos: 201, 400, 401, 403, 404, 409. Nunca 200 en un error.

UX cuidada

Diseño propio y uniforme, mensajes claros y modales en lugar de alert().

03 · Backend

NestJS: módulos y validación

// main.ts
app.setGlobalPrefix('api');
app.enableCors({ origin: CORS_ORIGIN.split(',') });
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,            // descarta lo no declarado
    forbidNonWhitelisted: true, // ...o responde 400
    transform: true,            // query → DTO tipado
  }),
);
app.useStaticAssets('uploads', { prefix: '/uploads/' });
@Get(':id')
obtener(
  @Param('id', ParseObjectIdPipe) id: Types.ObjectId,
  @UsuarioActual() usuario: PayloadJwt,
) { ... }

DTOs con class-validator

@IsEmail · @Matches (contraseña: 8+, mayúscula, número) · @MaxLength · @IsDateString · @IsMongoId · @IsIn. Mensajes en español.

Paginación tipada

@Type(() => Number) + @IsInt + @Min(0) / @Min(1) @Max(50) con defaults offset=0, limit=10.

Imágenes

FileInterceptor en memoria con filtro de tipo y 5 MB; se escriben a disco después de validar, así no quedan archivos huérfanos.

Errores consistentes

Excepciones de Nest (Conflict, Forbidden, NotFound…) → cuerpo { message, error, statusCode }.

06 · Autenticación

JWT de punta a punta

1

Contraseña

Se guarda con bcrypt.hash(pw, 10). En el login se compara con bcrypt.compare; el hash nunca sale de la API (select: false + toJSON).

2

Firma

JwtModule global con JWT_SECRET y expiresIn: '15m'. Registro y login devuelven { usuario, token }.

3

Guard

JwtAuthGuard lee el Bearer, verifica firma y vencimiento, y deja el payload en la request para @UsuarioActual().

4

Autorizar / refrescar

Autorizar busca al usuario actual en la base; refrescar re-firma el mismo payload con 15 minutos nuevos.

// payload del token
{
  "sub": "6adf9b4d94aac876...",   // _id
  "correo": "leo@mail.com",
  "nombreUsuario": "leo10",
  "perfil": "usuario",       // rol
  "iat": 1793044304,
  "exp": 1793045204           // iat + 900 s
}
// eliminar: autor o administrador
const esAutor = publicacion.autor.equals(usuario.sub);
if (!esAutor && usuario.perfil !== Perfil.Administrador) {
  throw new ForbiddenException(...);  // 403
}
publicacion.activa = false;           // baja lógica

07 · Consultas

Un listado, una agregación

this.publicacionModel.aggregate([
  { $match: { activa: true, autor? } },
  { $addFields: { cantidadMeGusta: { $size: '$meGusta' } } },
  { $facet: {
      total: [{ $count: 'n' }],
      publicaciones: [
        { $sort: orden },     // fecha | meGusta, desempate _id
        { $skip: offset },
        { $limit: limit },
        ...this.vista(usuarioId), // $lookup autor + conteo
      ],
  } },
]);

Orden por me gusta

No se puede ordenar por el largo de un array con find(): se calcula cantidadMeGusta y se ordena sobre ese campo.

Total + página en un viaje

$facet devuelve el total para la paginación y la página pedida en la misma consulta.

Respuesta lista para la UI

Cada publicación trae autor (campos públicos), cantidadMeGusta, meGustaYo y cantidadComentarios; el array de ids no se expone.

08 · Frontend

Angular moderno

Standalone + signals

Sin NgModules. Estado con signal, computed y linkedSignal; detección OnPush sin zone.js.

Interceptor

Guards

09 · Sesión

El reloj de la sesión

Al abrir la app

Pantalla de carga con spinner mientras /auth/autorizar valida el token: válido → publicaciones; inválido → login.

Cualquier 401

El interceptor cierra la sesión, redirige al login y explica el motivo en un modal.

Reloj robusto

El aviso se calcula desde que llegó el token más su duración (exp − iat), así un desfase de hora con el servidor no lo adelanta.
